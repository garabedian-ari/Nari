NARI — PURE HTML, CSS EN JAVASCRIPT

Dit pakket bevat de volledige meerpagina-website van Nari, zonder framework,
database of buildstap. Je kunt de site openen door index.html te dubbelklikken.

PAGINA'S
- index.html — homepagina
- diensten.html — diensten en aanpak
- prijsindicatie.html — interactieve prijsberekening
- abonnementen.html — hosting- en onderhoudsabonnementen
- werkwijze.html — proces in vier stappen
- faq.html — veelgestelde vragen
- contact.html — contactformulier

ANDERE BESTANDEN
- styles.css — alle vormgeving en responsive instellingen
- script.js — mobiel menu, calculator, FAQ, formulier en animaties
- assets/nari-hero.png — hero-afbeelding

PUBLICEREN
Upload de volledige map naar een host voor statische websites. Houd de
bestandsnamen en de map assets ongewijzigd, zodat alle links blijven werken.

AANPASSEN VOOR GEBRUIK

- Controleer alle prijzen en omschrijvingen voor commerciële publicatie.
